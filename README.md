# SystemDesign (LLD in Java)

This repository contains **Low Level Design (LLD)** implementations in **Java**, focusing on **Object-Oriented Programming (OOP)** concepts, **SOLID principles**, and commonly used **Design Patterns**.

It is intended as a **learning + interview-prep repository** for backend / SDE roles.

---

## 📌 Topics Covered

### 🔹 Core OOP Concepts
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism

### 🔹 SOLID Principles
- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

### 🔹 Design Patterns Implemented
- **Singleton Pattern**
- **Factory Pattern**
- **Observer Pattern**
- **Strategy Pattern**
- **Decorator Pattern**
- **Command Pattern**
- **Adapter Pattern**
- **Facade Pattern**
  
Each pattern is implemented with **simple, readable Java code** to clearly demonstrate:
- Intent
- Structure
- When & why to use the pattern
